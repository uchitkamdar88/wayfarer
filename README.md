# WAYFARER — Personal Travel Planner

> **Every journey deserves a story.**
> Discover places, plan thoughtfully, and travel your way.

WAYFARER is a client-side travel discovery and itinerary planner. It uses your trip preferences to create a personalized, day-by-day travel plan with destination-specific recommendations, route guidance, budget estimates, and practical travel information.

## Features

- **Seven-step trip planner** for destination, dates, travelers, pace, accommodation, dining, and budget preferences.
- **Curated destination guides** with attractions, hotels, dining, seasonal advice, and practical tips.
- **Day-by-day itineraries** with activities grouped into natural time-of-day blocks and geographically organized routes.
- **Non-repeating sightseeing** across a trip, while allowing practical repeats such as transit hubs and accommodation.
- **Nearby recommendations** to discover relevant places and excursions around the itinerary.
- **Budget calculator** with an itemized estimate and adjustable expense categories.
- **Travel companion** for destination-aware itinerary suggestions and adjustments.
- **Saved trips** stored in the browser, with JSON backup and restore.
- **PDF and print exports** for offline reference.
- **Responsive interface** for desktop and mobile screens.

## Getting started

### Requirements

- Node.js 18 or later
- npm

### Install dependencies and start the development server

```bash
npm install
npm run dev
```

Vite prints the local URL in the terminal.

### Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm test` | Run the automated test suite |
| `npm run build` | Type-check and create a production build in `dist/` |
| `npm run preview` | Preview the production build locally |

## Project structure

```text
src/
  components/       Shared interface components
  data/             Destination catalog and curated destination bundles
  features/         Planner, itinerary, budget, guides, maps, and exports
  lib/
    assistant/      Local travel companion logic
    budget/         Budget calculations and formatting
    destination/    Bundle construction and data validation
    pdf/            PDF export
    recommendation/ Itinerary generation and nearby recommendations
    storage/        Saved and active trip persistence
    validation/     Date and trip input validation
  styles/           Global styles
  types/            Shared TypeScript models
test-suite.ts       Automated tests
```

Destination data is organized under `src/data/destinations/` and registered centrally in `src/data/registry.ts`. Add or update destination content there and in the associated data bundle.

## Testing and production build

Run the automated test suite and production build with:

```bash
npm test
npm run build
```

The test suite checks destination data and validation, itinerary generation, budget calculations, and other core planning behavior. The build runs the TypeScript compiler before producing the optimized static site.

## Deployment

WAYFARER is a static single-page application. Deploy the contents of `dist/`, generated by `npm run build`. The repository includes configuration for both platforms:

- **Netlify:** `netlify.toml`
- **Vercel:** `vercel.json`

Both configurations build with `npm run build` and route application paths to the SPA entry point.

## Data and privacy

The planner does not require an account, backend, or API key. Active and saved itineraries are stored in the browser's local storage and are not automatically synced between devices. Use the trip-library backup and restore options to move saved trips. The application loads its web fonts from Google Fonts.
